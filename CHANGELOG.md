# История изменений

## 5.0.1-manual-value-9-currency-stable-icons

- Текущая рабочая сборка перенесена в линейку модулей **LipatoS**.
- ID пакета изменён на `lipatos-gatherer`.
- Сохранено пространство данных `gatherer`, чтобы не ломать существующие страницы, флаги и настройки мира.
- Пути шаблонов, иконок, API и сокета обновлены для пакета `lipatos-gatherer`.
- Сохранён ручной ввод значения проверки для D&D5e.
- Сохранена автоматическая выдача валюты из результатов `cp`, `sp`, `gp`, `ep`, `pp`.
- Сохранены приватные сообщения о добыче для ГМ и владельца персонажа.
- Пользовательские иконки меди, серебра и золота оптимизированы до 256×256 без изменения логики модуля.
