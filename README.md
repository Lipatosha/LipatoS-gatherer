# LipatoS - Сбор ресурсов

Модуль для **Foundry Virtual Tabletop 14**, основанный на Gatherer, для сбора ресурсов, охоты и поиска добычи через таблицы бросков.

## Версия

**5.0.2-manual-value-9-currency-stable-icons**

## Возможности

- создаёт специальные страницы журнала Gatherer на основе RollTable;
- позволяет настраивать таблицу добычи, количество попыток, время восстановления и требования;
- поддерживает сбор ресурсов с NPC и существ через назначенную страницу Gatherer;
- для D&D5e позволяет вводить итог проверки вручную вместо открытия системного окна броска;
- поддерживает добычу валюты из текстовых результатов `cp`, `sp`, `gp`, `ep`, `pp`;
- найденные монеты автоматически добавляются в валюту персонажа;
- использует отдельные иконки валюты;
- сообщения о найденной добыче видят ГМ и владелец персонажа, который выполнял сбор;
- предметы из таблицы автоматически выдаются персонажу согласно результату и количеству.

## Важно об ID модуля

Для этого модуля внутренний ID **намеренно сохранён `gatherer`**. Gatherer предоставляет собственный тип страниц журнала `gatherer.gatherer`, а Foundry привязывает такие типы к ID пакета. Изменение ID на `lipatos-gatherer` сделало бы существующие страницы Gatherer несовместимыми.

Поэтому репозиторий и видимое название относятся к линейке **LipatoS**, но технический ID остаётся `gatherer`, чтобы сохранить совместимость с существующим миром, флагами, настройками и страницами журнала.

Оригинальный Gatherer и эту сборку одновременно устанавливать не нужно — эта сборка заменяет его.

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте ссылку на манифест:

`https://raw.githubusercontent.com/Lipatosha/LipatoS-gatherer/main/module.json`
